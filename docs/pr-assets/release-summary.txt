RELEASE NOTES (verbatim, blank lines removed)
  **[Now patched to fix version number]**
  ## Added Features
  - ListenBrainz scrobbling
  - Track duration shown in library
  - Ukrainian language support
  - Norwegian language support
  - Hebrew font added
  ## Removed Features
  - (**for now**) Removed Last.fm functionality
  - *This is easily undoable in the case that last.fm changes their policies or you want to make your own fork to turn it back on*
  ## Other Changes
  - Removed Kofi QR code from easter egg
  - Added check that SD card is available before allowing OTA update
  - Firmware packer stripped out unneeded files to save space
  - (Developer Mode) Added toggle to boot sonix_player copied off of the SD card for easier development
  - Code changes to improve the language handling
  ## How to Install This?
  1. Download the `.upt` file for your device (e.g. `R1.upt` if you're installing this onto your R1)
  2. Place that `.upt` file at the root of your SD card (i.e. not in a folder)
  3. In system settings, press the option to update via SD card
  - If you can't do that, you can enter this update mode by holding Volume Up while powering on the device
  **If your device already has Sonix v1.3.1 or newer, you can update via OTA instead. That automatically updates to the latest release. You'll see that as an option in the settings, and you'll see these release notes when you're prompted whether you want to install it.**
  *Note: On first install, some R1 users have had a weird glitchy screen show up. But it always fixes itsself after a reboot. We're working to figure out what exactly that is.*
